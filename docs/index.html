Case 02

Bulk Account System

Lets operations open savings accounts in bulk from a single Excel upload.

  • Excel batch parsing and row validation with Apache POI
  • Existing-customer matching with Jaro-Winkler and Levenshtein similarity
  • Maker-checker approval with full audit logging
  • Civil-registry (Dukcapil) verification, tested locally against SoapUI mocks

Impact: One Excel upload opens a whole batch of haji savings accounts, with every row validated, matched against existing customers and approved through maker-checker.

  • JHipster
  • Spring Boot
  • Angular
  • Apache POI

Case 03

Legal Monitoring System

A workflow app for submitting documents to the legal team and tracking every review.

  • Performance audit pinpointing slow datalists, inbox queries and PDF storage
  • Rewrote the reviewer inbox query around the assignment table
  • Fixed assignee-resolution logic in BeanShell scripts
  • PDF annotation plugin so reviewers can mark up documents directly

Impact: Pinpointed the slow datalists, inbox queries and PDF storage behind the sluggish reviewer inbox, and rewrote the inbox query around the assignment table.
